# Why I moved back to pure HTML/CSS

The modern web ships megabytes of JavaScript just to render static text. 

I built this site to be fast and simple. No React hydration, no virtual DOM diffing, just a raw stream of HTML parsed instantly by the browser.

Using a few Google Fonts and minimal CSS is enough to achieve a clean look that loads in milliseconds.
